# 1–2-кезеңді тексеру

Тексеру ортасы: Windows, Python 3.14.3, Streamlit 1.64.0. Алғашқы тесттер жасанды деректер және қате сценарийлер арқылы орындалды. Кейін берілген нақты кейс деректері де төменде сипатталған қосымша тексеруден өтті.

## Орындалған тексерулер

- `python -m pytest -q`: **30 тест өтті**. Оның ішінде Parquet оқу, міндетті өрістер, қате мәндер, int64 дәлдігі, сомалар, толық емес файл жиыны, артық файл, бақылау шектеулері және Streamlit демо сценарийі бар.
- `python -m pip check`: бұзылған тәуелділіктер жоқ.
- Командалық жолмен жасанды үш файл жасау және тексеру есебін шығару: PASS.
- `http://127.0.0.1:8501`: HTTP 200.
- Браузерде «Демо деректермен тексеру»: жасанды деректер туралы белгі, 16 клиент, 15 байланыс, 17 операция, 4 seed көрсетілді.
- Браузер арқылы үш Parquet файлы нақты жүктелді, «Файлдарды тексеру» сәтті аяқталды.
- «Кестелерді қарау» арқылы жүктелген кесте ашылды.
- «Тексеру есебін жүктеу · JSON»: браузерде жүктеу оқиғасы расталды.
- Жүктелген `edges.parquet` тізімнен алынып, қайта тексерілді: міндетті файлдың жоқ екені туралы түсінікті қате көрсетілді.
- Браузер консолінде осы тексерулер кезінде error деңгейіндегі хабарлама жоқ.
- 390 × 844 тар экранда негізгі файл жүктеу және демо батырмалары көрінеді, бағандар бірінің астына бірі орналасады.

## Осы кезеңге кірмейтін тексерулер

2 248 нақты клиент бойынша рөлдер, кластерлер, басымдықтар, үш міндетті аналитикалық CSV, 5 минуттық толық пайплайн және OpenAI/NVIDIA қосылымдары кейінгі кезеңдерге жатады. Бұл мүмкіндіктер іске асырылды деп есептелмейді. API кредиттері пайдаланылған жоқ.

## Нақты деректермен қосымша тексеру

2026-09-23 күні `Downloads/data (1)/data` ішіндегі үш нақты Parquet файлы оқылды. Валидатор: `valid=true`; міндетті өрістер/идентификаторлар/сомалар/операциялар саны бойынша блоктайтын қате жоқ. Браузер арқылы файлдарды жүктеу және тексеру сәтті: 2 248 клиент, 3 119 байланыс, 4 840 аударым, 81 seed. Бақылау шектеулері интерфейсте көрінеді. Толық аудит — [INPUT_AUDIT.md](INPUT_AUDIT.md). Ұйымдастырушы файлдары өзгертілген жоқ.

## 2-кезеңнің тексеруі · 2026-09-23

- Толық жинақ: `python -m pytest -q` — **45 тест өтті**, 4.71 секунд. Графтағы циклдер, бірнеше seed-ден жету, оқшау клиент, бағытталған орталықтық, салмақталған PageRank, үлкен gid, уақыт шекарасы, қайталанатын операциялар, бос аударым кестелері және кіріс ретін өзгерту қамтылған.
- Streamlit AppTest: демо → граф → оқшау seed карточкасы → деректерді ауыстырғанда бұрынғы графты тазарту. Қосымша нақты деректермен карточкаларды тексеру сәтті.
- CLI тесттері: 18–19 таңбалы gid дәлдігімен CSV шығару, барлық клиент пен сомалардың сақталуы, жарамсыз кіріске есеп шығармау.
- `python -m pip check`: тәуелділік қатесі жоқ. NetworkX 3.7 және SciPy 1.18.1 бекітілген.
- Нақты кейстің CLI есебі: **2 248 клиент, 3 119 байланыс, 35 бөлік; 1.48 секунд**. Осы уақытқа валидация мен граф көрсеткіштерін есептеу кіреді; файлдарды оқу/экспорт және болашақ кезеңдер кірмейді. Бұл толық жобаның өнімділігі туралы қорытынды емес.
- Нақты веб есебі: барлық 2 248 клиент сақталды, **35 бөлік, 19 оқшау клиент, ең үлкен бөлік 1 877**. Алғашқы браузер есебі 3.75 секунд.
- Браузерде «Берілген кейсті ашу» → «Граф көрсеткіштері» → есептеу сәтті.
- `gid=100000000011452100` таңдалды: идентификатор дәл көрінеді; кіріс 110 000 ₸, шығыс 16 685 ₸, 3 жіберуші/1 алушы, 7 өзге seed, 1–2 күндік үлес 28.6%; бес бағытталған жол көрсетілді.
- «Күндік аударымдар» диаграммасы шолғышта көрінеді; «Нәтижелерді жүктеу» арқылы клиент көрсеткіштері CSV жүктеу оқиғасы расталды.
- Деректер мен нәтижелер `data/`, `output/` ішінде, Git-тен шығарылған. Сыртқы API шақырылған жоқ.
