# 6-кезең: тексеру және хакатонға тапсыру

> **Қазіргі нұсқа:** аудиттен кейін аналитика және интерфейс жаңартылды, нәтижелер мен жинақтар қайта жасалды. Соңғы тексеру — [RELEASE_REVIEW_KK.md](RELEASE_REVIEW_KK.md). Төмендегі кезеңдік өлшемдер тарихи.

**Аяқталды · 2026-09-23.** ТЗ-дегі негізгі есептеу, түсіндірме, CSV және карта дайын. Жеке таза Python ортасында орнату мен есептеу тексерілді; архитектура, демо сценарийі, қазылар сұрақтары және жергілікті тапсыру жинағы жасалды. Нақты API сынағы пайдаланушының «Әзірге кілтсіз дайындай бер» шешімімен кейінге қалды.

## Осы кезеңде не жасалды

1. `requirements.txt` ішіндегі 44 бекітілген пакет `output/wheelhouse` ішіне жүктелді. `setup.ps1` енді `-VenvDir` және `-Wheelhouse` параметрлерін қабылдайды.
2. Бөлек `output/stage6/clean-env` ортасы жасалды: Python 3.14.3, Windows x64, `include-system-site-packages=false`. Орнату `--no-index --find-links` арқылы орындалды. `pip check` қатесіз өтті.
3. Қабылдау скрипті шикі Parquet → үш CSV есептеуін екі жаңа Python процесінде орындады. Әр процесте Python socket/DNS шақырулары бұғатталды; API өшірулі. Желіге шығу әрекеті тіркелмеді.
4. CSV шарттары тәуелсіз тексерілді: бағандар, нақты gid жиыны, алты рөл, ұпайлар, дәлел ұзындығы, кластер құрамы/seed/ішкі сома және басымдық реті. Екі есептің үш CSV файлы байт деңгейінде бірдей; кіріс файлдарының SHA-256 хэштері өзгермеген.
5. Нақты деректердегі интерфейс логикасы сыртқы қосылымдар бұғатталған AppTest арқылы, карта мен үш мысал клиент нақты браузерде тексерілді. Аралас сан/мәтін фактілерін кестеде көрсету кезінде Arrow автоматты түрлендіру ескертуі түзетілді; бастапқы фактілердің типтері сақталады.
6. README-ге миллион түйінге масштабтау жоспары қосылды. [Архитектура](architecture.html), [5 минуттық демо](DEMO.md), [қазыларға жауаптар](JURY_QA.md) дайын.

## Дайын файлдар қайда

Жоба түбіріндегі `output/submission/`:

- `moneymap-submission.zip` — код, README, құжаттар, тесттер, карта ресурстары/лицензиялары, үш CSV, JSON тексеру есептері және SHA-256 manifest.
- `moneymap-offline-win-py314.zip` — сол жинақ және Windows x64 / Python 3.14 үшін дайын 44 wheel пакеті.
- `results/nodes_roles.csv`, `results/clusters.csv`, `results/top_nodes.csv` — ТЗ-дегі негізгі нәтижелер.
- `results/run_report.json` — конфигурация, кітапхана нұсқалары, кіріс хэштері және есептеу уақыты.
- `results/acceptance_report.json` — екі іске қосудың шарттары, уақыттары, CSV хэштері және PASS күйі.

Архив ашылғанда есептер `results/`, тексеру есептері `verification/`, құжаттар `docs/` ішінде болады. Шикі үш Parquet, `.env`, API кілттері, виртуалды орта және шығын журналы архивке кірмейді. Нәтижелерде нақты gid бар; бұл жергілікті хакатон тапсыру жиыны, жалпыға жарияланған сайт/репозиторий емес. Ұйымдастырушыға жіберу осы кезеңде орындалған жоқ.

## Басқа компьютерде қайталау

1. Python **3.14 x64** орнатылған Windows компьютерінде архивті жеке папкаға ашыңыз. Offline архив Python-ның өзін қамтымайды. Басқа ОС/архитектура бұл wheel жинағымен тексерілген жоқ.
2. Ұйымдастырушы берген үш түпнұсқа файлды жоба ішіндегі `data/case` папкасына салыңыз. Файл атаулары: `nodes.parquet`, `edges.parquet`, `transactions.parquet`.
3. Ашылған жоба папкасында PowerShell арқылы орнатыңыз:

```powershell
# Offline архив үшін:
powershell -ExecutionPolicy Bypass -File .\setup.ps1 -Wheelhouse .\wheelhouse

# Негізгі архив үшін, алғашқы орнатуда интернет бар кезде:
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```

Екі орнату командасының өзіңіздегі архивке сәйкес біреуін орындаңыз.

4. Міндетті есепті бір командамен жасаңыз:

```powershell
.\.venv\Scripts\python.exe -m moneymap run --data-dir data/case --out output/submission/results
```

5. Вебті іске қосыңыз:

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

Браузерде **http://127.0.0.1:8501/** → «Берілген кейсті ашу» → «Желі картасы» → «Картаны дайындау». Терминалды ашық ұстаңыз. Тоқтату — `Ctrl+C`.

## Қабылдауды және архивті қайта жасау

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts\verify_submission.py --data-dir data/case --out output/submission/results
.\.venv\Scripts\python.exe scripts\package_submission.py
```

Offline жинақ та керек болса, соңғы команданың орнына:

```powershell
.\.venv\Scripts\python.exe scripts\package_submission.py --wheelhouse output/wheelhouse
```

Пакеттер алдын ала жүктелмеген болса, Windows x64 / Python 3.14 ортасында интернет бар кезде дайындауға болады:

```powershell
.\.venv\Scripts\python.exe -m pip download --only-binary=:all: -r requirements.txt --dest output/wheelhouse
```

Қабылдау скрипті ағымдағы Python ортасын пайдаланады; екі CLI есебін де қайта шығарады. Архив құрастырушы PASS есебі мен ағымдағы CSV хэштерінің сәйкестігін талап етеді. `MANIFEST.sha256.json` архив ішіндегі әр файлдың SHA-256 мәнін қамтиды (manifest-тің өзін қоспағанда).

## Тексеру шекарасы және келесі әрекет

- Таза **виртуалды орта** тексерілді; бөлек жаңа Windows орнатылған физикалық компьютер тексерілген жоқ.
- Python socket/DNS бұғаттауы CLI және AppTest логикасына қолданылды. AppTest Windows ішкі loopback қызметіне рұқсат береді. Бұл операциялық жүйе firewall-ы немесе физикалық ажыратылған желі сынағы емес. Браузер canvas-ы бөлек қалыпты localhost сессиясында тексерілді.
- Нақты OpenAI/NVIDIA кілті, аккаунттағы модель қолжетімділігі, тірі қазақша жауап сапасы және провайдер төлемі тексерілмеді. Кредит жұмсалған жоқ. Қосу жолы — [STAGE5.md](STAGE5.md).
- Ground truth жоқ: accuracy, precision немесе заңсыздық анықтау пайызы өлшенбеді. Рөлдер мен кластерлер талдаушының тексеруіне арналған гипотезалар.

Ендігі практикалық жұмыс — [DEMO.md](DEMO.md) бойынша бес минуттық қорғауды қайталап көру. Нақты AI қажет болса, кілтті өз компьютеріңізде қосқаннан кейін аз лимитпен бөлек қабылдау сынағын орындау керек.
