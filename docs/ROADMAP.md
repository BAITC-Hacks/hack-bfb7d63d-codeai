# MoneyMap: кезең-кезеңмен орындау

## 1-кезең. Жұмыс ортасы және деректерді қабылдау

**Нәтиже:** браузерде ашылатын жергілікті интерфейс; үш Parquet файлын тексеру; шартты демо; JSON тексеру есебі; командалық іске қосу; қате сценарийлерге тесттер.

API қажет емес. Рөлдер мен нақты кейс нәтижелері жасанды түрде көрсетілмейді.

## 2-кезең. Граф және көрсеткіштер

**Аяқталды.** NetworkX қосылды. Алдымен `nodes` ішіндегі барлық клиенттер, содан кейін бағытталған байланыстар енгізіледі. Жіберушілер/алушылар саны, бақыланған кіріс/шығыс, компоненттер, бірнеше seed-ден жету, орталықтық және уақыттық белгілер есептеледі. Нақты кейс: 2 248 клиент, 35 бөлік, 19 оқшау клиент. Формулалар мен 4 аралық есеп — [STAGE2.md](STAGE2.md).

`depth=4` — бақылау шекарасы. Seed кірістері толық емес. Көрінетін аударымдардың арақатынасы толық балансқа теңестірілмейді. `gid` мәндері int64 дәлдігімен сақталады.

**Аяқталу шарты:** әр клиенттің тексерілетін метрикалары бар; оқшау seed жоғалмайды; шағын белгілі графтармен есептер тексерілген; браузерде көрсеткіштер көрінеді.

## 3-кезең. Рөлдер, кластерлер және тексеру кезегі

Алты рөл үшін формалды ереже және конфигурациядағы шектер жасаймыз. Әр рөл — тексеруге арналған болжам. `role_score` — эвристикалық сенімділік, `priority_score` — бөлек басымдық көрсеткіші. Louvain параметрлері мен кездейсоқтық дәні бекітіледі. Кластер нөмірлері тұрақтандырылады.

Міндетті файлдар:

```text
nodes_roles.csv: gid, role, role_score, cluster_id, priority_score, evidence
clusters.csv: cluster_id, n_nodes, n_seed, sum_kzt_internal, top_gids, hypothesis
top_nodes.csv: rank, gid, role, priority_score, why
```

**Аяқталу шарты:** барлық 2 248 түйін қамтылған; ұпайлар 0–1; evidence бос емес және ≤200 таңба; нақты кейсте топ ≥20; API-сыз бір команда барлық файлды шығарады.

## 4-кезең. Желіні зерттеу интерфейсі

Бағытталған граф, рөл/кластер түсі, gid іздеу, таңдалған түйіннің 1–2 қадамдағы көршілері, транзакциялар және метрикалары бар карточка. PyVis ресурстары жергілікті беріледі. Бүкіл граф пен таңдалған бөлік арасында ауысу қарастырылады.

**Аяқталу шарты:** браузерде кез келген gid бойынша іздеу, картадан байланыстарды көру, түсіндірменің деректермен сәйкестігі тексеріледі.

## 5-кезең. AI көмекші

Алдымен OpenAI арқылы «Неге маңызды?» және «Анықтама дайындау» қосылады. API-ге тек Python дайындаған қажетті фактілер жіберіледі. Шектеулі функциялар: клиент карточкасы, басымдық тізімі, кластер қорытындысы, ортақ алушылар. Қолжетімді NVIDIA endpoint белгілі болғанда балама провайдер қосылады.

Кілттер `.env` немесе орта айнымалыларында; браузер мен Git ішінде сақталмайды. Қысқа сұраулар, кэш, токен шығынын тіркеу және уақыт шегі қосылады. Модельдің жауап схемасы, gid және сандық фактілері тексеріледі. Ешкімді кінәлі деп жарияламайды, сыртқы деректермен байытпайды.

**Аяқталу шарты:** нақты функция нәтижелеріне сүйенген жауап; қате/өшірулі API кезінде негізгі талдау мен CSV жұмысын жалғастырады; бюджет пен қолжетімді модельдер нақтыланған.

## 6-кезең. Қорытынды тексеру және тапсыру

Таза ортада орнату мен толық есептеу; нақты датасетте ≤5 минутты өлшеу; схемалар, барлық клиенттер, детерминизм, шекаралық жағдайлар, интерфейс және желісіз жұмыс. README ішіне нақты критерийлер, шектер, шектеулер және миллион түйінге масштабтау жоспары жазылады. Архитектура диаграммасы және 5 минуттық демо дайындалады.

**Аяқталу шарты:** міндетті репозиторий, README, 3 CSV, схема және демо дайын; өтпеген тексерулер мен нақты шектеулер ашық көрсетілген.
