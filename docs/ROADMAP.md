# MoneyMap: кезең-кезеңмен орындау

**Ағымдағы толықтыру:** негізгі пайплайн және қосымша талдау нақты 2 248 клиенттік кейспен қайта тексерілді. 91 кластер, топ-30; негізгі есеп шамамен 3–4 секундта орындалады. Маршруттар/циклдер, топаралық ағындар, байланыстырушы клиенттер, екі алып тастау стратегиясы, төрт аномалия ережесі, шектеулі қазақша/орысша мәтіндік сұрақтар және сарапшының CSV бағалауы қосылды. `--extended` немесе `run.ps1 -Extended` 12 қосымша файл шығарады. Өзекті мәртебе: [CRITERIA.md](CRITERIA.md); өлшенген дәлел: [VERIFICATION.md](VERIFICATION.md). Төмендегі бұрынғы кезең сандары тарихи жазба ретінде сақталған.

## 1-кезең. Жұмыс ортасы және деректерді қабылдау

**Нәтиже:** браузерде ашылатын жергілікті интерфейс; үш Parquet файлын тексеру; шартты демо; JSON тексеру есебі; командалық іске қосу; қате сценарийлерге тесттер.

API қажет емес. Рөлдер мен нақты кейс нәтижелері жасанды түрде көрсетілмейді.

## 2-кезең. Граф және көрсеткіштер

**Аяқталды.** NetworkX қосылды. Алдымен `nodes` ішіндегі барлық клиенттер, содан кейін бағытталған байланыстар енгізіледі. Жіберушілер/алушылар саны, бақыланған кіріс/шығыс, компоненттер, бірнеше seed-ден жету, орталықтық және уақыттық белгілер есептеледі. Нақты кейс: 2 248 клиент, 35 бөлік, 19 оқшау клиент. Формулалар мен 4 аралық есеп — [STAGE2.md](STAGE2.md).

`depth=4` — бақылау шекарасы. Seed кірістері толық емес. Көрінетін аударымдардың арақатынасы толық балансқа теңестірілмейді. `gid` мәндері int64 дәлдігімен сақталады.

**Аяқталу шарты:** әр клиенттің тексерілетін метрикалары бар; оқшау seed жоғалмайды; шағын белгілі графтармен есептер тексерілген; браузерде көрсеткіштер көрінеді.

## 3-кезең. Рөлдер, кластерлер және тексеру кезегі

**Аяқталды.** Алты рөл үшін формалды ереже және `config/roles.json` шектері жасалды. Әр рөл — тексеруге арналған болжам. `role_score` — ережеге сәйкестік ұпайы, `priority_score` — бөлек басымдық көрсеткіші. Louvain параметрлері мен кездейсоқтық дәні бекітілген, кластер нөмірлері тұрақтандырылған. Барлық 2 248 клиент сақталады; әдепкі нәтиже — 91 кластер және топ-30. Ережелер: [STAGE3.md](STAGE3.md).

Міндетті файлдар:

```text
nodes_roles.csv: gid, role, role_score, cluster_id, priority_score, evidence
clusters.csv: cluster_id, n_nodes, n_seed, sum_kzt_internal, top_gids, hypothesis
top_nodes.csv: rank, gid, role, priority_score, why
```

**Аяқталу шарты:** барлық 2 248 түйін қамтылған; ұпайлар 0–1; evidence бос емес және ≤200 таңба; нақты кейсте топ ≥20; API-сыз бір команда барлық файлды шығарады.

## 4-кезең. Желіні зерттеу интерфейсі

**Аяқталды.** Бағытталған интерактивті граф, рөл/кластер/буын түстері, толық gid іздеу, 1–2 қадамдық айнала, бір кластер және бүкіл желі режимдері іске асырылды. Түйінді басқанда толық көрсеткіштері, тікелей байланыстары, жеке операциялары және seed жолдары бар карточка ашылады. Карта сүзгілері есептелген ұпайлар мен карточка сомаларын өзгертпейді. vis-network JS/CSS ресурстары жергілікті беріледі; PyVis 0.3.2 пакетінің ресурстары алынған, Python PyVis тәуелділігі қосылған жоқ. Нұсқаулық: [STAGE4.md](STAGE4.md).

**Аяқталу шарты орындалды:** толық картада 2 248 клиент/3 119 байланыс; оқшау клиент жоғалмайды; картадан басу мен толық gid іздеу карточканы ашады; 131 тест өтті. Нақты браузердегі тексерулер [VERIFICATION.md](VERIFICATION.md) ішінде.

## 5-кезең. AI көмекші

**Кілтсіз нұсқасы дайын.** Бес дайын тапсырмаға қосымша қазақша/орысша шектеулі мәтіндік сұрақтар бар: клиент, топ-1–10, кластер, ортақ алушылар, өзге seed жолдары, кіріс/шығыс контрагенттері және дерек толықтығы. Күн/сома/рөл сүзгілері, терістеу және екіұшты сұрақтар нақтылауды қажет етеді. Кілтсіз есеп пен жүктеу жұмыс істейді; қосымша AI батырмасы OpenAI/NVIDIA адаптерлеріне тек дайын фактілер мен уақытша клиент белгілерін береді. Бастапқы сұрақ пен gid сәйкестігі осы компьютерде қалады.

Кілттер `.env` немесе орта айнымалыларында; браузер мен Git ішінде сақталмайды. Әдепкі 20 сұрау / 200 000 токен / OpenAI $1 есептік шек, атомарлы SQLite резерві, токен журналы, сессия кэші және timeout бар. NVIDIA шығыны доллармен болжанбайды. Жауап схемасы мен фактілерге сілтемелер тексеріледі; сандық мәндерді Python бастапқы деректен көрсетеді. Мәтіннің мағынасына талдаушы тексеруі қажет. Нұсқаулық: [STAGE5.md](STAGE5.md).

**Іске асырылды:** жергілікті фактілер, мәтіндік сұрақтар, бюджет/кэш/қате сценарийлері, API өшірулі кезде жұмыс. **Қалғаны:** нақты кілттермен провайдерге сұрау жіберу, аккаунттағы модель қолжетімділігі мен қазақша жауап сапасын тексеру. Жалпы мақсаттағы еркін чат және шектеусіз сұрау тілі іске асырылды деп мәлімделмейді.

## 6-кезең. Қорытынды тексеру және тапсыру

**Қайта тексеру құралдары дайын.** `scripts/verify_submission.py` шикі файлдардан нәтижені екі рет шығарып, үш CSV шарттарын, уақытын, хэштерін және Python желі шақыруларын тексереді. `scripts/package_submission.py` қабылданған нәтижелер мен бастапқы кодтан тапсыру архивін жасайды. README, миллион түйінге масштабтау жоспары, архитектура және 5 минуттық демо біріктірілді.

**Бұрынғы дәлел:** 44 пакет таза Python 3.14.3 виртуалды ортасына `--no-index` арқылы орнатылған; 260 тест және 19 нақты дерек AppTest тексеруі өткен. Шикі файлдан үш CSV-ге дейін 1,762315 с, жаңа Python процесімен 2,427316 с өлшенген; қайталанған CSV байттары бірдей, кіріс хэштері өзгермеген. Екі тапсыру архиві сол ортада жасалған. Толық тарихи нәтиже мен қайталау командалары — [STAGE6.md](STAGE6.md).

**Осы көшірмеде расталды:** 440 автоматтандырылған тест, нақты 2 248 клиент, топ-30, үш міндетті CSV және ≤5 минут шарты; кеңейтілген 12 есеп, браузердегі топаралық ағын, аномалиялар және мәтіндік сұрақтар. **Бөлек қажет:** шынайы сарапшы белгілері, нақты API сапасы, жаңа таза компьютер және миллиондық көлемдегі тексеру. Жоқ транзакциялар толықтырылды немесе нақты ұйымдастырушы расталды деп айтылмайды.
