# 5-кезең: AI көмекші және кілтсіз жергілікті есеп

Пайдаланушының **«Әзірге кілтсіз дайындай бер»** деген таңдауы сақталды. Көмекшінің интерфейсі, фактілерді дайындау, жергілікті есеп, екі API-ға арналған қосылу коды және жауапты тексеру дайын. Қазір API әдепкіде өшірулі. Нақты OpenAI немесе NVIDIA сұрауы жіберілген жоқ, кредит жұмсалмады.

Осы кезеңде жаңа машиналық оқыту моделін үйрету қажет емес. Python графты, рөлдерді және тексеру басымдығын есептейді. Кейін API қосылғанда дайын тілдік модель осы фактілерге сүйеніп қысқаша түсіндірме жазады.

## Қазір қалай қолдануға болады

1. [Жергілікті сайтты](http://127.0.0.1:8501/) ашып, **«Берілген кейсті ашу»** таңдаңыз.
2. **«Анықтама»** бөліміне өтіп, **«Көмекшіге деректерді дайындау»** басыңыз. Бұл жергілікті есептеулерді орындайды; API шақырмайды.
3. **«Анықтама түрі»** тізімінен қажетті жұмысты таңдаңыз және клиентті не кластерді көрсетіңіз. Әдепкіде қысқа талдаушы анықтамасы таңдалады.
4. **«Нақты фактілер және есептеу өрістері»** бөлімін ашып, есепке қандай деректер кіретінін қараңыз.
5. **«Анықтаманы дайындау · API-сыз»** басыңыз. Есептің басында **«Жергілікті есеп · AI қолданылған жоқ»** деп жазылады.
6. **«Анықтаманы жүктеу · TXT»** арқылы есепті сақтаңыз. Фактілер мен клиент белгілерінің жергілікті сәйкестігін JSON түрінде де жүктеуге болады.

Жеке клиент анықтамасындағы **«Картадан тексеру»** батырмасы дәл осы gid-тің картасы мен операциялар карточкасын ашады; деректер мен есептер қайта жүктелмейді.

Кілт жоқ кезде **«AI түсіндірмесін алу»** батырмасының белсенді болмауы — күтілетін күй. OpenAI мен NVIDIA арасында ауысу да өздігінен сұрау жібермейді.

Провайдер, модель, кілтті қосу нұсқаулығы, бюджет және API батырмасы **«Қосымша: LLM түсіндірмесі және баптаулар»** ішінде жиналған. Негізгі анықтама оларды баптауды қажет етпейді. API қатесінен кейін жасалған жергілікті есеп «шығын жоқ» деп жарияламайды: алдыңғы әрекет токен жұмсауы мүмкін.

Сайт ашылмаса, PowerShell ішінде:

```powershell
cd D:\OSPanel\domains\hack-bfb7d63d-codeai
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

## Бес тапсырма

| Экрандағы атауы | Не таңдайсыз | Нәтижеге кіретін фактілер |
|---|---|---|
| Рөл мен басымдықтың толық негізі | Бір клиенттің gid мәні | Толық көрсеткіштер, нақты орындалған рөл шарты мен шектері, жеті басымдық үлесі және бақылау шектеулері |
| Талдаушыға қысқа анықтама | Бір клиенттің gid мәні | Негізгі кіріс/шығыс, рөл шарты, ең үлкен үш басымдық үлесі және клиенттің жағдайына сай келесі дерек сұрауы |
| Кімді алдымен тексеру керек? | 1–10 клиент | Бүкіл жиын бойынша басымдығы жоғары клиенттер, рөлдің шарты, нақты жеті үлес пен салмақ, кіріс, буын және seed белгісі |
| Кластерді түсіндіру | Кластер нөмірі | Кластер көлемі, ішкі айналымы, рөлдер құрамы, seed және 4-буын саны, басымдығы жоғары бес мүшеге дейін |
| Ортақ алушыларды табу | 2–5 әртүрлі gid | Әр таңдалған жіберушіден тікелей ақша алған ортақ алушылар, сол жіберушілерден түскен сомалар мен операциялар саны |

Ортақ алушылар үшін gid мәндерін жаңа жолмен, бос орынмен, үтірмен немесе нүктелі үтірмен бөлуге болады. Қайталанған, белгісіз және дәл бүтін сан емес gid қабылданбайды.

Ортақ алушы барлық таңдалған жіберушінің **тікелей** алушысы болуы керек. Бірнеше қадам арқылы жету жеткіліксіз. Таңдалған жіберушілердің өздері нәтиженің алушылар тізіміне кірмейді. Ортақ алушы оннан көп болса, таңдалған жіберушілерден түскен жиынтық сома бойынша алғашқы он алушы көрсетіледі; толық, көрсетілген және үзіндіге кірмеген алушылар саны бөлек беріледі.

Барлық тапсырма толық бақыланған деректерді пайдаланады. Картадағы сүзгі кірісті, шығысты, рөлді немесе басымдықты өзгертпейді. Бірдей операция жолдары жойылмайды. Seed кірісінің толық еместігі, 4-буындағы шығыс шектеуі және құрылымдық жолдың дәл сол ақшаның қозғалысын дәлелдемейтіні есепке қосылады.

## Нақты деректер және уақытша клиент белгілері

Бір сұрауға ең көбі 100 шағын факт дайындалады. Әр фактінің `F001` сияқты нөмірі, түсіндірмесі, мәні, өлшем бірлігі және есептелген өрісі бар. Сан, күн, ұпай немесе рөл Python есебінен алынады; бастапқы еркін мәтіндік `evidence`, `hypothesis` және `why` өрістері провайдерге көшірілмейді.

Орындалған рөл шарты сенімді кодтан, ағымдағы конфигурациядан және клиенттің нақты мәндерінен жасалады. Координатор үшін осы жиында есептелген квантиль шегі де беріледі. Қысқа рейтингте жеті нақты үлес бір мәтіндік фактке біріктірілген: бұл топ-10 үшін 100 факт шегін сақтайды. Клиенттің толық есебінде үлестер жеке фактілер күйінде қалады.

Қысқа анықтама толық фактілерді тізіп қайталамайды. Ол шекарадағы клиентке келесі буын шығысын, seed үшін толық кірісті, уақыттық қайшылықта ертерек кезеңді, ал оқшау клиентке операциялардың қамтылуын тексеруді ұсынады. Бұл ұсыныс жергілікті және детерминирленген.

Клиенттер сыртқы сұрауда `C001`, `C002` сияқты уақытша белгілермен аталады. **Белгі → толық gid сәйкестігі осы компьютерде қалады.** Ұзын gid Python ішінде дәл бүтін санмен, браузердегі сәйкестік кестесінде мәтінмен сақталады.

API кейін қосылғанда таңдалған провайдерге тапсырманың қысқаша қаржылық көрсеткіштері, уақытша белгілер және шектеулер жіберіледі. Бастапқы Parquet файлдары, толық операциялар кестесі және gid сәйкестік картасы сұрауға қосылмайды. Белгілер қолданылғанымен, жіберілетін сомалар мен құрылымдық көрсеткіштер нақты деректер болып қала береді.

Жүктелетін жергілікті JSON және TXT есептерінде толық gid сәйкестігі бар. Олар пайдаланушыға арналған жергілікті нәтижелер; модельге жіберілетін қысқартылған пакеттен өзгеше.

## API-ды кейін қосу

Бұл қадамды қазір орындаудың қажеті жоқ. Қосу уақыты келгенде жоба түбіріндегі `.env.example` файлын үлгі ретінде пайдаланып, `.env` файлын толтырыңыз. Егер `.env` бұрыннан бар болса, оны үстінен көшірмей, қажетті жолдарын ғана өңдеңіз.

Негізгі параметрлер:

| Параметр | Әдепкі мәні немесе қызметі |
|---|---|
| `MONEYMAP_AI_ENABLED` | `false`; API-ды қосқанда ғана `true` болады |
| `OPENAI_API_KEY` | OpenAI кілті; бастапқыда бос |
| `NVIDIA_API_KEY` | NVIDIA API Catalog кілті; бастапқыда бос |
| `OPENAI_MODEL` | `gpt-4.1-mini-2025-04-14` |
| `NVIDIA_MODEL` | `meta/llama-3.3-70b-instruct` |
| `MONEYMAP_AI_MAX_OUTPUT_TOKENS` | Әдепкіде 1200; жауап көлемінің шегі |
| `MONEYMAP_AI_TIMEOUT_SECONDS` | Әдепкіде 45; жауапты күту параметрі |
| `MONEYMAP_AI_BUDGET_USD` | `1.00`; OpenAI үшін жергілікті есептік шығын шегі |
| `MONEYMAP_AI_MAX_REQUESTS` | `20`; тіркелетін сұрау әрекеттерінің шегі |
| `MONEYMAP_AI_MAX_TOTAL_TOKENS` | `200000`; кіріс пен шығыс токендерінің жиынтық шегі |

Бір провайдердің кілтін енгізу жеткілікті. `.env` сақталған соң сайттан **«API күйін жаңарту»** басып, **«AI провайдері»** тізімінде сол провайдерді таңдаңыз. Кілт пен `MONEYMAP_AI_ENABLED=true` екеуі де қажет. Сыртқы сұрау тек **«AI түсіндірмесін алу»** батырмасы басылғанда жіберіледі.

Кілтті чатқа, браузердегі еркін мәтін өрісіне немесе Git-ке енгізудің қажеті жоқ. Ол сервер жағында `.env` не процесс ортасынан оқылады; интерфейске және шығын журналына жазылмайды. `.env` Git елемейтін файлдар қатарына қосылған. Процесс ортасында аттас параметр орнатылған болса, ол `.env` мәнінен басым болады.

Қазір тек жоғарыда көрсетілген екі модельге арналған конфигурация қабылданады. Кез келген басқа модель атауын немесе сыртқы сервер мекенжайын еркін енгізу қолдау таппайды: модельді ауыстырғанда жауап пішімі мен шығын есебін де тексеру керек.

OpenAI жолы Responses API мен JSON Schema бойынша Structured Outputs қолданады. Таңдалған GPT-4.1 mini нұсқасы модель құжатында көрсетілген; құрылымды жауаптың өзі фактілердің мағынасын дәлелдемейді. [GPT-4.1 mini ресми құжаты](https://developers.openai.com/api/docs/models/gpt-4.1-mini), [Structured Outputs нұсқаулығы](https://developers.openai.com/api/docs/guides/structured-outputs).

NVIDIA жолы `integrate.api.nvidia.com` қызметіндегі Llama моделінің chat completion API-ына арналған. Модель NVIDIA-ның LLM API тізімінде бар. Бұл кодта JSON пішімі нұсқаулық арқылы сұралады, кейін Python арқылы тексеріледі; модель деңгейінде қатаң JSON Schema орындалатынына кепілдік берілмейді. [NVIDIA LLM API құжаты](https://docs.api.nvidia.com/nim/re/reference/llm-apis).

Пайдаланушыға берілген NVIDIA токенінің нақты қай сервиске тиесілі екені әлі анықталмаған. Оның осы API-мен үйлесімділігі, екі модельге аккаунт қолжетімділігі және тірі сұраудың орындалуы кілтсіз кезеңде тексерілген жоқ.

## Жауап қалай тексеріледі

AI қысқаша қорытынды, фактілерге сілтемесі бар бақылаулар және алдын ала белгіленген келесі тексеру әрекеттерін қайтаруы керек. Нақты сандарды модельдің мәтінінен көшірмейміз: Python аталған фактілердің бастапқы мәндерін түсіндірменің жанында өзі шығарады.

Тексеру мыналарды бақылайды:

- JSON пішімі, міндетті өрістер, мәтін мен тізім көлемі;
- тек осы пакетте бар факт нөмірлеріне сілтеме жасалуы;
- тек берілген уақытша клиент белгілерінің қолданылуы;
- түсіндірме мәтінінде жаңа сан, күн немесе толық gid болмауы;
- айқын айыптау, кінәсіздік/қауіпсіздік туралы тұжырым және шотты бұғаттау сияқты қолдау таппайтын сөздік қорытындылар;
- толық ағылшынша мәтін және осы деректе жоқ шетел/офшор, жеке мекенжай не қолма-қол шығару туралы кейбір айқын тұжырымдар;
- аяқталмаған, бос немесе провайдер бас тартқан жауаптың көрсетілмеуі.

Тексеру өтпесе, сыртқы жауаптың орнына жергілікті есеп ұсынылады. Жүйе жауапты түзетуді сұрап API-ды автоматты қайта шақырмайды және басқа провайдерге өздігінен ауыспайды.

**Мәтін мағынасын талдаушы тексеруі керек.** Факт нөмірінің бар болуы оның сол сөйлемді шынымен дәлелдейтінін толық тексермейді. Сөздік сүзгі барлық ықтимал қате тұжырымды ұстай алмайды. Рөл, басымдық және кластер қылмыс не кінәлілік туралы шешім емес.

Сәтті API жауабынан кейін де негізгі экран жергілікті есептелген анықтаманы көрсетеді; LLM мәтіні бөлек ашылатын, тексеруді қажет ететін түсіндірме ретінде беріледі. Тілдің сөздік тексеруі қазақша сапаның толық бағасы емес. Бұл өзгерістер нақты API қолжетімділігін немесе тірі модель сапасын тексерді дегенді білдірмейді.

## Шығын, кэш және жергілікті журнал

Әдепкі шектер — жоба бойынша 20 сұрау әрекеті, 200 000 жиынтық токен және OpenAI үшін есептік 1 USD. Бұлар екі провайдерді қолданғанда да бір жергілікті журнал арқылы бақыланады. Бұл **сізге берілген 50 доллар кредиттің қалдығы емес**, әрі провайдер аккаунтындағы төлемге қойылған шек емес. NVIDIA үшін долларлық баға анықталмаған; оның сұрау саны мен токендері есептеледі, USD шығыны «белгісіз» болып қалады.

OpenAI-дың осы моделіне енгізілген есептік баға — миллион кіріс токеніне 0,40 USD және миллион шығыс токеніне 1,60 USD. Баға кестесі ресми модель құжатымен тексерілген; нақты аккаунт төлемі немесе нақты сұраудың құны әлі өлшенген жоқ. Провайдердің кіріс кэш жеңілдігі жергілікті есепте қолданылмайды. [GPT-4.1 mini бағасы](https://developers.openai.com/api/docs/models/gpt-4.1-mini).

Сұрау алдында болжамды токен мен шығын резерві сақталады. Провайдер пайдаланылған токендерді толық берсе, журнал соған жаңартылады. Usage белгісіз болса немесе жауапқа дейін байланыс үзілсе, резерв сақталады: белгісіз шығын нөл деп саналмайды. Қате сұрау да әрекет шегіне кіреді. Лимит жеткіліксіз болса, жаңа сұрау жіберілмейді.

Журнал `output/ai/usage.sqlite3` файлына жазылып, қолданба қайта іске қосылғанда сақталады. Онда провайдер, модель, уақыт, сұрау күйі, токендер және есептік шығын бар; кілттер, клиент идентификаторлары, сұрау мәтіні және жауап мәтіні сақталмайды. Интерфейстегі **«Қосымша: LLM түсіндірмесі және баптаулар»** бөлімі осы журналды көрсетеді.

Тексерілген жауаптар ағымдағы браузер сеансына қатысты сервер жадында ең көбі 30 нәтиже болып сақталады. Бірдей фактілер мен параметрлер үшін кэш қолданылса, жаңа API сұрауы болмайды. Кэш тұрақты файлға жазылмайды. Оның сәйкестігі тапсырмаға, толық фактілерге, шектеулерге, жергілікті gid сәйкестігіне, модельге және жауап параметрлеріне байланысты; басқа клиенттің ұқсас сандары бұрынғы жауапты қате қайта қолдандырмайды. Деректер немесе граф/рөл есебі жаңарса, көмекшінің күйі тазарады.

## Ішкі құрылым және тексерілген шек

| Файл | Міндеті |
|---|---|
| `moneymap/ai_facts.py` | Жергілікті фактілер, уақытша белгілер, дәл идентификаторлар және API-сыз есеп |
| `moneymap/ai_settings.py` | `.env` және орта параметрлерін құпия мәндерді көрсетпей оқу |
| `moneymap/ai_provider.py` | Таңдалған бір провайдерге шектелген сұрау жіберу, аяқталу мен көлемді тексеру |
| `moneymap/ai_budget.py` | SQLite арқылы сұрау, токен және шығын резервтерін сақтау |
| `moneymap/ai_response.py` | Жауап схемасы, сілтемелер мен мәтіндік шектеулер, жергілікті есепке айналдыру |
| `moneymap/ai_service.py` | Резерв → сұрау → тексеру → шығынды тіркеу → кэш тізбегі |
| `moneymap/ui_ai.py` | Бес тапсырма, жергілікті режим, провайдер күйі және нәтижені жүктеу |

HTTP үшін жобада бар `requests`, JSON схемасын тексеру үшін `jsonschema`, журнал үшін Python құрамындағы `sqlite3` қолданылады. Бұл кезеңге жаңа OpenAI/NVIDIA SDK немесе GPU кітапханасы қосылған жоқ.

Кілтсіз автоматты тексерулер фактілердің дұрыстығын, int64 дәлдігін, сыртқы пакетте gid болмауын, ортақ алушылардың нақты қиылысуын, шектеулі көлемді, кэшті, бюджет резервін, қате/аяқталмаған жауаптарды және интерфейс күйін қамтиды. Провайдер жауаптары тесттерде жасанды жауаптармен алмастырылған; тесттер нақты API-ға шықпайды. Соңғы толық тексеруде **253 тест 18,77 секундта өтті**. Қосымша тексеру мәліметтері [VERIFICATION.md](VERIFICATION.md) ішінде сақталады.

Браузерде нақты `100000002578405100` клиентінің кілтсіз есебі ашылды: бүкіл жиынның айналымы **365 890 012,01 ₸**, клиенттің кірісі **1 200 351 ₸**, шығысы **3 108 352 ₸**, бірегей алушылары **116**. AI сұрау батырмасы кілтсіз күйде өшірулі болды.

Ортақ алушылардың браузердегі мысалы да тексерілді: `100000000089154100` және `100000001102676100` жіберушілерінің бір ортақ алушысы — `100000003684369100`; осы екі жіберушіден оған **99 500 ₸**, **2 операция** түскен. TXT жүктеу жұмыс істеді. NVIDIA-ға ауысқанда алдыңғы провайдерге қатысты есеп тазарып, API батырмасы кілтсіз күйде өшірулі қалды.

Әзірге расталмаған бөліктер: нақты кілтпен провайдерге қосылу, аккаунттағы модель қолжетімділігі, тірі модельдің қазақша түсіндірме сапасы, нақты сұраудың токен шығыны мен төлемі. Оларды API қосуды шешкенде бөлек тексеру керек. Қазіргі аяқталған нәтиже — кілтсіз жұмыс істейтін талдау мен есеп және кейінгі API тексеруіне дайын қосылу қабаты.
