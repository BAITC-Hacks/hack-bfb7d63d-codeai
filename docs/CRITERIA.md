# HackAlem AI талаптарына сәйкестік

Ағымдағы жұмыс нұсқасы нақты үш Parquet файлымен қайта тексерілді: **2 248 клиент, 91 кластер, топ-30**; негізгі үш CSV-ге дейін **шамамен 3,6–4,1 секунд**, толық кеңейтілген CLI шамамен 6 секунд. Файлдар `data/case` ішінде жергілікті сақталады, Git құрамына кірмейді. Өзекті дәлел — [VERIFICATION.md](VERIFICATION.md).

`f3bcfe9` жаңартуымен келген бұрынғы таза орта журналдары тарихи анықтама ретінде сақталған. Төменде кеңейтілген ағымдағы жұмыс нұсқасының мүмкіндіктері берілген.

## Бес міндетті функция

| Талап | Іске асырылғаны | Осы компьютердегі тексеру және қалған жұмыс |

| Әр клиентке рөл, ұпай, негіз | Барлық бастапқы gid, алты рөл, [0,1] ұпайлар, бос емес ≤200 таңбалы evidence | Нақты 2 248 клиент сақталды; int64, оқшау және шекаралық жағдайлар тесттермен қамтылған. |
| Түсіндірілетін критерийлер | `config/roles.json`, `STAGE3.md`, клиент карточкасындағы ереже, метрика және басымдық үлестері | Рөл шектері мен өзіндік аударымдарға регрессия тексерілді. Рөл ұпайы калибрленген ықтималдық емес. |

## Осы толықтыруда қосылғаны

- `Қосымша талдау → Клиент анықтамасы`: нақты метрикаларға сүйенген қысқа анықтама, дерек шектеулері және келесі сұраулар; Markdown жүктеу. Мәтін жергілікті ережелерден құрастырылады.
- `Маршруттар мен циклдер`: екі бағыттағы жұптар, ұзындығы 2–5 болатын бағытталған циклдер, кемінде екі бөлек кіріс күнінде байқалған A → B → C үлгілері. Шығыс күні кіріс күнінен қатаң кейін және таңдалған 1–2 күн ішінде болуы керек; толық бақылау аралығы жоқ соңғы күндер есептен алынады.
- `Желі тұрақтылығы`: басымдық және тек seed тізімінен бірдей N клиент алып тастау салыстырылады. Қалған клиенттер, байланыстар, компоненттер және айналым беріледі. Seed — расталған төменгі деңгей емес; болашақ желі қайта құрылуы болжанбайды.
- `Топтар арасындағы ағын` және `Дерек толықтығы`: 212 бағытталған кластер жұбы, 385 байланыстырушы кандидат, әр клиенттің бақылау шектеулері мен келесі дерек сұраулары. Басқару иерархиясы мен толықтық пайызы бұлардан анықталмайды.
- `Аномалиялар`: ұқсас сома, күндік өсу, бір күндегі әртүрлі жіберушілер және бір буын ішіндегі көлем ауытқуы. Әдепкі кейсте 247 белгі: 41 + 140 + 66. Бұл бірегей клиенттер не расталған бұзушылық саны емес; сандық негіз бен салыстыру шектеулері көрсетіледі.
- `Сарапшы бағасы`: тәуелсіз белгілеу, бос CSV үлгісі, импорт/экспорт, дерек жиынының хэші. Accuracy/macro F1 тек бағаланған рөлдерде; толық precision@k алғашқы k клиент толық бағаланғанда ғана есептеледі. Белгісіз жауап теріс жауапқа айналмайды.
- Өзіне аударым енді бөлек жіберуші/алушы болып саналмайды. Бұл бес жіберуші не он алушы шегіне жалған жетуді түзетеді; ақша сомалары мен операциялар сақталады.
- Windows үшін Python табу және бір командамен іске қосу, [архитектура](ARCHITECTURE.md), [5 минуттық демо жоспары](DEMO.md), README ішіндегі миллион түйінге масштабтау жоспары толықтырылды.
- `AI көмекші`: бес дайын тапсырма және қазақша/орысша шектеулі мәтіндік сұрақтар; қосымша seed жолдары, кіріс/шығыс және дерек толықтығы. Танылмаған немесе қолдау жоқ шарттар қабылданбайды. API-сыз TXT/JSON есеп, OpenAI/NVIDIA адаптерлері, кэш және шығын шектері бар; нақты провайдер сынағы орындалмаған.
- `scripts/verify_submission.py`: екі қайта есептеу, CSV шарттары, кіріс/шығыс хэштері және ≤300 секундты тексеру. `scripts/package_submission.py`: қабылдау есебі мен ағымдағы CSV хэштері сәйкес келгенде тапсыру архивін жасау.

Маршрут іздеуі әдепкіде 50 000 цикл қадамы, 20 000 екі қадамдық кандидат және 100 нәтижемен шектеледі. Интерфейс іздеу/көрсету шегіне жетуді хабарлайды. Цикл, уақыттық сәйкестік және байланыс сомалары дәл сол ақшаның қозғалысын дәлелдемейді; тұрақтылық сценарийі болашақ аударымдарды болжамайды.

## Қалған шектеулер

1. **Көрінбейтін дерек.** Төртінші буыннан кейінгі, өзге банктегі, кезеңнен тыс және іріктеуге түспеген төмен сомалы аударымдар қалпына келтірілмейді. Бағдарлама нақты сұрауларды дайындайды; толық баланс пен толықтық пайызы белгісіз.
2. **Расталған рөлдер.** Сарапшы жұмыс процесі бар, бірақ бастапқы үш файлда толық эталондық белгілер жоқ. Бағаланған іріктеменің нәтижесі бүкіл желіге таралмайды; рөл/басымдық/аномалия ұпайлары калибрленген ықтималдық емес. Нақты ұйымдастырушы және басқару иерархиясы расталмайды.
3. **Тірі API және жалпы чат.** Мәтіндік сұрақтар қолдау бар шектеулі тапсырмаларға түрлендіріледі. Жалпы күрделі әңгімелесу моделі емес. OpenAI/NVIDIA аккаунтындағы қолжетімділік, тірі жауаптың қазақша сапасы және төлемі тексерілмеген; адаптерлер имитацияланған жауаптармен сыналды.
4. **Өнімділіктің шегі.** Нақты кейс қабылдауы орындалды; басқа таза компьютер, физикалық желі оқшаулауы және миллион түйіндегі өнімділік бөлек тексеруді қажет етеді. Аналитик уақытын үнемдеу мен нақты араласу тиімділігі өлшенбеген.

## Тапсыруға арналған файлдар

`run.ps1 -DataDir data/case -Out output/submission/results -Extended` негізгі үш CSV мен `run_report.json` шығарады; `extended/` ішіне 12 қосымша файл жазылады. Тікелей CLI баламасы — `python -m moneymap run --data-dir data/case --out output/submission/results --extended`. Толық файл тізімі мен сарапшы CSV нұсқаулығы [README](../README.md) ішінде. Вебте «Қосымша есептердің бәрін дайындау» сол әдепкі жинақты ZIP түрінде береді. Қабылдауды `scripts/verify_submission.py` арқылы қайталап, [STAGE6.md](STAGE6.md) бойынша `scripts/package_submission.py` көмегімен архивтеуге болады.
