## Что произошло с API

По запросу пользователя выполнены реальные вызовы через штатные `request_analysis`, `call_provider`, проверку ответа и журнал лимитов. Использовались только **синтетические демоданные**, задача `explain_client` для демоклиента `1005`; исходные финансовые данные кейса не передавались. Ключи не выводились и не включены в отчёты.

Первый запрос к каждому провайдеру завершился ошибкой. Затем сделано по одному отдельному диагностическому запросу для регистрации точного HTTP-статуса. Всего **4 попытки**, без автоматических повторов. Флаг включения менялся только в памяти проверочного процесса; `.env` не изменялся, приложение осталось в режиме API-off.

### OpenAI

Модель: `gpt-4.1-mini-2025-04-14`; endpoint: `https://api.openai.com/v1/responses`.

Получен **HTTP 401**. Текущие учётные данные не были приняты. Содержимое ключа и полный текст ошибки провайдера не публиковались. Эта проверка не устанавливает причину недействительности ключа и не доказывает наличие или отсутствие денег на аккаунте.

Для завершения проверки нужен действующий ключ с доступом к указанной модели, сохранённый локально в `OPENAI_API_KEY`. После этого следует включить `MONEYMAP_AI_ENABLED=true` и повторить один запрос по сценарию README. Само наличие строки ключа и статус «қосылған» успешную авторизацию не подтверждают.

### NVIDIA

Модель: `meta/llama-3.3-70b-instruct`; endpoint: `https://integrate.api.nvidia.com/v1/chat/completions`.

Получен **HTTP 410 Gone**. В [официальном каталоге NVIDIA](https://build.nvidia.com/meta/llama-3_3-70b-instruct) у этой модели `Free Endpoint` отмечен как `Deprecated`. Это согласуется с недоступностью используемого hosted-вызова. Доступность загрузки модели или партнёрского endpoint не означает работоспособность текущего адаптера.

Нельзя обещать исправление простой заменой ключа. Требуется выбрать доступную модель/вариант размещения, проверить условия доступа, обновить поддерживаемую конфигурацию и контракт адаптера, затем провести отдельный тест. Текущая `ai_settings.py` допускает только закреплённую модель NVIDIA; произвольная замена `NVIDIA_MODEL` в `.env` будет отклонена. Миграция модели в рамках этого аудита не выполнялась.

## Достаточно ли README для жюри

README дополнен по результатам этого контроля:

- Основная проверка решения не требует API; для дополнительного LLM достаточно одного работающего провайдера.
- Приведены отдельные настройки OpenAI и NVIDIA, модели и endpoint-адреса; ключи не нужно передавать в Git.
- Отдельно показаны результаты неудачных реальных запросов, чтобы не выдавать реализованный адаптер за работающую интеграцию.
- Описаны последовательность запуска, признак настоящего LLM-ответа и поведение при ошибке.
- Уточнено, что «API күйін жаңарту» перечитывает настройки, а не проверяет соединение.
- Описаны локальные лимиты, ошибки доступа/сети/формата и отличие локальной справки от текста модели.

Наличие инструкции не устраняет проблемы доступа к провайдерам. На текущую защиту можно воспроизводимо показывать граф, роли, очередь, кластеры, локальную справку и CSV. Успешный дополнительный LLM-сценарий пока демонстрировать нельзя.

## Повторение проверки и артефакты

Из корня проекта после установки зависимостей и добавления `data/case`:

```powershell
.\.venv\Scripts\python.exe -m pytest -q --junitxml=output/final-check/tests.xml
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe scripts\verify_submission.py --data-dir data/case --out output/final-check/results
```

Локальные артефакты проверки:

- `output/final-check/tests.xml` — полный pytest.
- `output/final-check/results/acceptance_report.json` — независимая приёмка и хэши.
- `output/final-check/results/` — три CSV и `run_report.json`.
- `output/final-check/live-api-report.json` — первый реальный запрос к каждому провайдеру.
- `output/final-check/live-api-diagnostic.json` — точные HTTP-коды повторной диагностики.

`output/` исключена из Git. Этот отчёт содержит проверенные итоговые сведения; локальные артефакты нужно воспроизвести либо передать отдельно. Автоматические pytest и приёмочная команда не обращаются к настоящим LLM; ручной сетевой сценарий описан в [README](../README.md).
