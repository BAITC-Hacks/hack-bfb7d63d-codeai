# Кейс талаптарының орындалуы

Тексерілген нұсқа: 2026-09-23. Толық сынақ есебі: [VALIDATION.md](VALIDATION.md).

## Міндетті нәтижелер

| Талап | Жобада қалай орындалды |
|---|---|
| Үш Parquet-тен бір іске қосуда нәтиже шығару | CLI үш CSV және толық JSON жасайды. Оқшауланған ортада, `.deps` жоқ бөлек код көшірмесінде толық CLI шамамен 3,4 секундта орындалды. Басқа операциялық жүйеде орындалуы өлшенген жоқ. |
| Барлық 2248 түйінге рөл, ұпай, кластер, басымдық, evidence | Барлық түйін мен оқшау шот сақталады; CSV бағандары талапқа сай, ұпайлар 0–1, evidence бос емес және 200 таңбадан аспайды. |
| Рөл тағайындаудың формалды ережелері | [METHODOLOGY.md](METHODOLOGY.md): шектер, рөл кезектілігі, басымдық салмақтары. Карточкада сандық негіздеме мен ұпай үлестері бар. |
| Топтау және әр топтың сипаттамасы | Louvain бойынша 110 қауымдастық; өлшемі, seed саны, ішкі айналым, негізгі шоттар және гипотеза экспортталады. |
| Кемінде 20 шот және бағытталған іздеу графы | TOP-20 CSV, барлық шот рейтингі, GID іздеу, рөл/буын/кластер сүзгісі, бағытталған граф. Толық көрініс 2248 шотты көрсетеді. |

README ішінде іске қосу жолы, архитектура сызбасы, бес минуттық көрсету
сценарийі және миллион түйінге масштабтау жоспары бар. Миллион түйіндік
жұмыс режимі іске асырылып, өлшенген мүмкіндік ретінде ұсынылмайды.

## Қосымша мүмкіндіктер

| Бұрын жетіспеген бөлік | Қосылған шешім және шегі |
|---|---|
| Белсенділіктің күрт өсуі | Күндік көлемді нөлдік күндерді қосқан басқа күндермен салыстыру; нақты шектер, күн және сандық evidence бар. |
| Жылдам қайта аудару және бірнеше төлеуші | 0–2 күндегі көлем сәйкестігі және бір күнде кемінде төрт түрлі төлеуші. Нақты сағаттық реттілік пен сол ақшаның ізі дәлелденбейді. |
| Қайталанатын маршруттар | 2–3 байланысты, кемінде екі күндік қайталануы бар бағыттар; күндер тізімі және графта белгілеу. |
| Циклдер | 2–4 байланысты бағытталған тұйық жолдар. Іздеу бюджеті мен қысқартылған тізімдер интерфейсте және JSON ішінде ашық көрсетіледі. |
| Аударымды бөлшектеу белгілері | Бір күндегі төрт немесе одан көп ұқсас сома; бір жұпқа не бірнеше алушыға аудару. Бұл ниетті немесе есептілік шегін айналып өтуді дәлелдемейді. |
| Сол буындағы шоттардан ауытқу | Кемінде сегіз шоттан тұратын бірдей depth тобында көлем мен контрагенттер бойынша салыстыру. |
| TOP-N тұрақтылығы | Интерфейсте TOP-1/3/5/10/20; API-де 1–100. Әр алынған түйіннен кейін компоненттер мен бағытталған қолжетімділік қайта есептеледі. |
| Сұрақ арқылы талдау | Ережелік көмекші және орнатылған жергілікті Qwen3 моделі. Нақты GID сілтемелері тексеріледі; аты-жөн/кінәлілік сұрақтарына дерек шегін тексеру ережесі жауап береді. Модель мәтінін аналитик тексереді. |
| PDF анықтама | Жалпы талдау немесе жеке шот есебі: көрсеткіштер, негіздеме, паттерн күндері, әдіс, шектеулер және келесі дерек сұрауы. |
| Уақыт бойынша ойнату | Нақты күндік аударымдарды немесе сол күнге дейінгі жиынтықты көрсету; ойнату/кідірту/толық кезеңге қайту. Рөлдер толық кезең бойынша қалады. |
| Толық граф және зерттеу жолы | Барлық шотты көрсету, байланыстарды сирету, бес қадамдық сценарий: үміткер → паттерн → дәлел → сұрау → PDF. |
| Қайта орнатылуын тексеру | `scripts/verify_clean.py` бастапқы кодтың бөлек көшірмесінде оқшауланған venv, толық тест жиыны және CLI орындалуын тексереді. Үш ОС үшін CI конфигурациясы бар; қашықтағы CI нәтижесі әлі алынған жоқ. |
| Дәлел қабылдау | Құжатқа сілтеме, сарапшы, тексеру мәртебесі, рөл белгісі және өзгерістер тарихы датасетке байланыстырылып сақталады. Файлдың түпнұсқалығы автоматты расталмайды. |
| Рөлдердің сапасын бағалау | CSV/JSON белгілерін импорттау, үлгі жүктеу, accuracy/precision/recall/F1 және қате матрицасы. Қамтылған үлес көрсетіледі; белгі жоқ кезде пайыз шығарылмайды. |
| Қосымша аударымдар | Дереккөзі мен transaction_id бар аударымдарды кеңейтілген графқа қабылдау, қайталауды тексеру, жаңа түйіндерді рөлі анықталмаған деп көрсету. Бастапқы дерекпен қайталанбауы — пайдаланушы мәлімдемесі. |
| Терең зерттеу | 12 байланысқа дейін жол/цикл іздеу, курсормен жалғастыру және ұзындығы шектелмеген ең қысқа жол. Толықтық тек көрсетілген іздеу ауқымына қатысты. |
| Қайта құрылу сценарийі | Бұрынғы байланыстың таңдалған үлесін жасанды алмастырушы түйіндермен қайта құру; бастапқы/алып тасталған/жорамал графтарды салыстыру. Бұл нақты бейімделуді болжау емес. |

Бұрыннан бар «Бақылау шегі» деректің толық еместігін және келесі сұрауларды
көрсетуді жалғастырады. Жаңа функциялар үш міндетті CSV схемасын және
бастапқы рөл/басымдық есептеуін өзгертпейді.

## Тек осы деректен шешуге келмейтін мәселелер

- **Нақты ұйымдастырушы кім?** Құрылымдық үміткерлер көрсетіледі. Дәлелді
  қабылдау құралы дайын, бірақ пайдаланушы растайтын құжаттар әзірге жоқ екенін айтты.
- **Көрінбейтін ақша қайда кетті?** Басқа банк, төрт қадамнан арғы жол,
  іріктеу шегінен төмен сома немесе берілмеген кезең ойдан қалпына келтірілмейді.
  Қосымша дерек сұрауы мен келген аударымдарды қабылдау құралы дайын; деректің өзі әлі берілмеген.
- **Топ бұғаттаудан кейін қалай бейімделеді?** Қайта құрылу сценарийін
  есептеу дайын. Болашақ нақты жаңа шоттар мен әрекеттерді болжайтын бақыланған мысалдар жоқ.
- **Рөлдердің дәлдігі қанша?** Белгілерді қабылдау және метрикаларды есептеу
  дайын; расталған дұрыс рөлдер жинағы жоқ. Бағдарламалық тесттер classification accuracy емес.
