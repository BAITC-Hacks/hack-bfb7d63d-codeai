# Synthetic output examples

These three CSV files were generated by `python run.py --demo` from the
deterministic synthetic fixture (214 nodes, 383 directed pairs and 1,520
transactions). They are provided as reviewable output artifacts and are
**not results from Freedom's official challenge dataset**.

Regenerate them with the demo command or replace them with actual batch outputs
after the authorized dataset becomes available. `role_score` is rule strength,
not a calibrated probability. Methodology: `docs/METHODOLOGY.md`.
