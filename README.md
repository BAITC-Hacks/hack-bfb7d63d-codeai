# MoneyMap · HackAlem AI

Банк талдаушысына арналған жергілікті қаржылық байланыстарды зерттеу құралы.

**Ағымдағы нәтиже: 1–2-кезең аяқталды — деректерді тексеру, бағытталған граф және көрсеткіштер.** Барлық клиенттер, соның ішінде оқшау түйіндер сақталады. Кіріс/шығыс, байланыстар, орталықтық, seed жолдары және күндік көрсеткіштер есептеледі. Рөлдер, басымдық, Louvain кластерлері және AI кейінгі кезеңдерде қосылады. Нақты кейс деректері Git-ке енгізілмеген.

Ұйымдастырушының Downloads ішіндегі нақты үш Parquet файлы кейін қаралып, 1-кезең валидаторынан және браузердегі жүктеу сценарийінен өтті. Материалдардың мақсаты, расталған сандар мен starter шектеулері: [docs/INPUT_AUDIT.md](docs/INPUT_AUDIT.md).

## Жергілікті вебті ашу

Windows PowerShell ішінде жоба папкасына өтіңіз:

```powershell
cd D:\OSPanel\domains\hack-bfb7d63d-codeai
powershell -ExecutionPolicy Bypass -File .\setup.ps1
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

Браузерде **http://127.0.0.1:8501** ашыңыз. Бірінші орнатудан кейін тек `start.ps1` жеткілікті. Сервер жұмыс істеуі үшін терминалды ашық ұстаңыз; тоқтату — `Ctrl+C`. Егер 8501 порты бос болмаса:

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1 -Port 8502
```

Сонда http://127.0.0.1:8502 ашылады. Жоба осы компьютерде Python 3.14.3 арқылы тексеріледі; барлық орнатылған тәуелділік `requirements.txt` ішінде бекітілген. Басқа компьютерде осы Python нұсқасын қолдану ұсынылады. Тәуелділіктерді алғашқы орнату интернетті қажет етеді; 1–2-кезең жұмысына интернет қажет емес. Бұрын орнатқан болсаңыз, жаңа NetworkX/SciPy тәуелділіктері үшін `setup.ps1` қайта іске қосыңыз.

macOS/Linux үшін балама:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

Бұл платформаларда бөлек тексеру әлі орындалмаған.

## Бірінші рет көру

1. Осы компьютерде «Берілген кейсті ашу» басыңыз. Батырма `data/case` ішінде үш файл бар кезде көрінеді. Ұйымдастырушы файлдарының жергілікті көшірмесі дайын; бастапқы файлдар өзгертілмеген.
2. «Граф көрсеткіштері» бөліміне өтіп, «Граф көрсеткіштерін есептеу» басыңыз.
3. Кестені кіріс/шығыс, көршілер саны, PageRank немесе басқа көрсеткішпен сұрыптаңыз; буын бойынша сүзіңіз.
4. `gid` тізімінен клиентті таңдап, көрсеткіштері мен seed-ден жету жолдарын қараңыз.
5. «Желі бөліктері», «Күндік аударымдар» және «Нәтижелерді жүктеу» ішкі бөлімдерін ашыңыз.
6. Басқа компьютерде үш Parquet файлын бірге жүктеп, «Файлдарды тексеру» басыңыз. «Демо деректермен тексеру» жасанды мысал үшін қолжетімді.

Деректер ауысқанда алдыңғы граф есебі тазартылады; жаңа жиын үшін есептеуді қайта басу қажет. Интерактивті желі картасы 4-кезеңде қосылады, қазір есептер кесте, күндік диаграмма және мәтіндік жол түрінде беріледі.

Сол жақтағы «Демо файлдарын жүктеу» батырмасы ZIP береді. Оны ашып, ішіндегі үш Parquet файлын қайта жүктеу арқылы толық жүктеу сценарийін сынауға болады. Демо толығымен жасанды: 16 клиент, 15 байланыс, 17 операция. Бұл нақты кейс және рөлдер туралы дайын жауап емес.

## Қабылданатын деректер

| Файл | Міндетті бағандар |
|---|---|
| `nodes.parquet` | `gid`, `depth`, `is_seed` |
| `edges.parquet` | `src`, `dst`, `sum_kzt`, `n_tx`, `depth` |
| `transactions.parquet` | `src`, `dst`, `date`, `sum_kzt` |

Әр файл үшін жүктеу шегі — 20 МБ. Кіріс деректері сервер жадында өңделеді; веб жүктемелер дискіге автоматты түрде сақталмайды. Шикі файлдар өзгертілмейді. API кілті бұл кезеңде қажет емес, сыртқы модельдерге сұрау жіберілмейді.

Тексеру мына жағдайларды қамтиды:

- файлдың Parquet ретінде оқылуы, міндетті және қайталанатын бағандар;
- бос мәндер, дәл бүтін int64 идентификаторлар, `depth` аралығы, `is_seed` мәндері;
- қайталанатын `gid` және `src → dst` жұптары;
- `nodes` ішінде жоқ аударым қатысушылары;
- сомалардың оң және шекті болуы, операция санының бүтін болуы;
- күндердің оқылуы және транзакцияларды жұп бойынша қосқанда `edges` сомалары/санына сәйкестігі;
- деректердің шектеулері: 4-буын, толық емес seed кірістері, байланысы жоқ seed, шығыстың көрінетін кірістен артық болуы, кезең және 5 000 ₸ шегі.

Қателер талдауға дайын күйге өтуге кедергі болады. Ескертулер бақыланатын үзіндінің шектеулерін түсіндіреді. Оқылған жолдар жасырын түрде жойылмайды немесе біріктірілмейді. Ұйымдастырушы README бойынша `nodes.depth` — клиент алғаш табылған буын (0–4), `edges.depth` — байланыс табылған қадам (1–4). Екеуі графта бөлек сақталады; жалпы валидатор `edges.depth` үшін 0–4 аралығын қабылдайды.

## Екінші кезеңнің нәтижесі

Нақты кейс: **2 248 клиент, 3 119 байланыс, 4 840 операция, 81 seed**. Бағытты уақытша ескермегенде 35 байланысқан бөлік бар, оның 19-ы оқшау клиент. Ең үлкен бөлікте 1 877 клиент. Бақыланған айналым — **365 890 012,01 ₸**, кезең — 2026-07-01–2026-07-31.

Көрсеткіштер мен формулалар: [docs/STAGE2.md](docs/STAGE2.md). Браузерде ұзын `gid` мәтін ретінде беріледі. CSV файлдарын Excel-ге импорттағанда да `gid` бағанын мәтін түрінде таңдаңыз.

**API кілттерін қазір енгізу қажет емес.** OpenAI 5-кезеңде дайын сандарды түсіндіру және қысқа аналитикалық анықтама жасау үшін қосылады. NVIDIA қолжетімді endpoint/model нақтыланғаннан кейін балама провайдер бола алады. Осы кезеңде модель үйретілмейді, екі провайдерді қатар шақыру қажет емес; API кредиттері жұмсалмайды.

## Командалық жолдағы тексеру

Жасанды файлдар жасау (бар файлдарды үстінен жазбайды):

```powershell
.\.venv\Scripts\python.exe -m moneymap demo --output-dir data/demo
```

Бір командамен тексеру есебін алу:

```powershell
.\.venv\Scripts\python.exe -m moneymap validate --data-dir data/demo --output output/validation_report.json
```

Шығу коды: `0` — деректер жарамды; `1` — тексеру қатесі; `2` — команданы пайдалану немесе файлдық операция қатесі. Бұл бірінші кезеңнің **тексеру есебі**. ТЗ-дегі `nodes_roles.csv`, `clusters.csv`, `top_nodes.csv` үшін толық пайплайн 3-кезеңде қосылады.

Граф пен 2-кезеңнің төрт есебін бір командамен алу:

```powershell
.\.venv\Scripts\python.exe -m moneymap analyze --data-dir data/case --out output/stage2
```

Нәтиже: `node_metrics.csv`, `components.csv`, `daily_activity.csv`, `graph_summary.json`. Команда алдымен деректерді тексереді; жарамсыз жиынға есеп шығармайды. Қайта іске қосқанда осы төрт есеп жаңартылады. Кіріс файлдары өзгертілмейді.

Тесттер:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

## Құрылым

```text
app.py                 Streamlit интерфейсі
moneymap/data.py        Parquet оқу және тексеру
moneymap/demo.py        Толығымен жасанды сынақ деректері
moneymap/graph.py       Барлық түйіні бар граф және көрсеткіштер
moneymap/ui_graph.py    Көрсеткіштер, клиент таңдау, күндік диаграмма
moneymap/reports.py     2-кезеңнің CSV/JSON есептері
moneymap/__main__.py    Командалық жол интерфейсі
tests/                 Деректер мен жұмыс сценарийін тексеру
setup.ps1              Жергілікті ортаны орнату
start.ps1              Жергілікті вебті іске қосу
requirements.txt       Бекітілген тәуелділіктер
docs/ROADMAP.md         Келесі кезеңдердің нақты жұмысы
```

Кейс деректерін, API кілттерін және `.env` файлын Git-ке қоспаңыз. `data/`, `output/`, `.venv/` және құпия конфигурация `.gitignore` арқылы шығарылған.
